此目录存放「示例照片」来源图。

程序首次启动写入示例数据时，会把本目录里的图片**复制**进照片库（只入库，不抢占当前背景）；
数据目录里的副本才是程序真正使用的文件，所以这里的原图删除或移动都不影响已导入的照片。

仓库里**不包含**任何个人照片，克隆下来后请自己放两张进去（竖幅更好看）：

```powershell
cd app
npm run sample-photos      # 生成两张中性占位图（660×1435）
```

或者直接把你自己的任意 jpg/png 拷进本目录（支撑的格式：jpg / png / gif / bmp / tiff / heic）。
打包时本目录会被复制为程序资源 `resources/seed-photos`。
